# Stockage Azure

**État du module** · Prévu

## Choisir où stocker les données et qui peut y accéder

Je créerai des conteneurs Blob et des partages Azure Files. Pour chacun, je vérifierai qu’un accès prévu fonctionne et qu’un accès sans les droits est refusé.

Je prendrai ensuite une charge de travail comme exemple. Je comparerai les niveaux d’accès et les options de redondance pour expliquer ceux que je choisirais. Je testerai aussi une stratégie de cycle de vie et j’examinerai les prérequis de SMB et de NFS.

Je consignerai mes réglages et mes résultats dans le [modèle d’exercice](../exercise-template.md).
